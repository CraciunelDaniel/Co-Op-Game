# Co-Op Game

Кооператив на 2–4 игрока. Unity 6, Netcode for GameObjects, VContainer, Facepunch.Steamworks.

## Запуск

- `-transport utp` — подключение по IP:port (по умолчанию).
- `-transport steam` — Steam P2P (AppID 480, `steam_appid.txt` рядом с exe). Если Steam не запущен — UTP.
- `-profile <имя>` — отдельный игрок для каждого окна на одном ПК.

Steam-транспорт: https://github.com/Unity-Technologies/multiplayer-community-contributions/tree/main/Transports/com.community.netcode.transport.facepunch

**Управление:** WASD + мышь, F — создать предмет, E — взять/отпустить, G — бросить, X — удалить, Q — цвет, Tab — список игроков.

## Архитектура

Модули: Core (интерфейсы, без сети и Steam), Gameplay, Networking, Transports, Steam, UI, Bootstrap.
Транспорт и Steam подключаются только в `BootstrapLifetimeScope`, остальной код работает через интерфейсы.

## Сеть

- Хост отвечает за предметы, список игроков и сессию.
- Игрок управляет своим персонажем сам, остальные видят его с интерполяцией.
- Физику предметов считает только хост. Захват, бросок и удаление проверяет хост; при захвате предмет передаётся игроку, при броске возвращается хосту.
- Если двое хватают один предмет, хост отдаёт его первому.
- Подключение проверяет версию, лимит игроков и повторный вход; причина отказа видна в меню.
- Late-join получает текущую сцену, предметы и цвета. Если хост выходит, все возвращаются в меню.

## Известные проблемы

- При высоком пинге (150+ мс) захват на бегу или падающего предмета может не сработать, а брошенный предмет на мгновение задерживается в руке. Исправить можно учётом пинга при проверке дистанции на хосте.
- Движение игрока не проверяется хостом.

Время: ~20 часов.
